Problem Statement — Hangman Game

Guessing and learning new words manually can be less interactive and may not provide an engaging way for users to improve their word recognition and spelling skills. Therefore, there is a need for a simple computerized game that can provide an interactive word-guessing experience.

The Hangman Game is developed using Python to provide an easy and interactive way for users to guess a randomly selected word letter by letter. The system provides a limited number of attempts, checks the validity of each input, and displays the correctly guessed letters. The game makes word guessing more engaging while demonstrating important Python programming concepts such as functions, loops, conditional statements, file handling, lists, strings, random selection, and regular expressions.
